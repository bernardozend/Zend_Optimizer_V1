## 🇧🇷 Português

**Zend - Optimizer** é uma ferramenta profissional para administração de sistemas e otimização de infraestrutura Windows.

### 🛠️ Funcionalidades:
- **Limpeza Nuclear**: Remove arquivos temporários, caches de navegadores e pontos de restauração.
- **Otimização de Infra**: Desativa hibernação e armazenamento reservado (~7GB+ de ganho imediato).
- **Análise de Perfis**: Lista o tamanho de cada usuário e a data do último acesso.
- **Segurança**: Gera Hash SHA-256 para auditoria de integridade.

---

## 🇺🇸 English

**Zend - Optimizer** is a professional CLI tool for Windows system administration and infrastructure optimization.

### 🛠️ Features:
- **Nuclear Cleanup**: Removes temporary files, browser caches, and system restore points.
- **Infra Optimization**: Disables hibernation and reserved storage (immediate ~7GB+ gain).
- **Profile Analysis**: Lists the size of each user profile and the last access date.
- **Security**: Generates a SHA-256 Hash for integrity auditing.
